# 双均线策略回测研究（贵州茅台 2020-2026）

## 1. 策略逻辑
用 MA5 与 MA20 的交叉作为买卖信号：
快线（MA5）上穿慢线（MA20）买入，下穿卖出。
信号当日收盘后产生，次日持仓（防前视偏差）。

## 2. 核心结果
| 指标 | 双均线策略 | 买入持有 |
|---|---|---|
| 总收益 | +28.3% | +32.5% |
| 年化收益 | +3.9% | +4.4% |
| 年化波动 | 17.7% | 25.3% |
| 夏普比率 | 0.22 | 0.18 |
| 最大回撤 | −40.7% | −45.2% |
交易次数：100（7年50次死叉+50次金叉）

## 3. 关键发现
- 2021-02-26 死叉（见顶后仅10个交易日）躲过主跌浪
- 2021-06 死叉踏空 9 月主升浪（含历史第三大涨日 +8.99%）
- 策略波动降低 30%，夏普反超，属"减震器"型策略

## 4. 局限性（必读）
1. 单只股票样本，结论不可外推
2. 未计手续费（100次交易，万三佣金将拖累约6%收益）
3. 参数 5/20 为经验值，未做参数敏感性测试（存在过拟合嫌疑）
4. 信号以收盘价计算，实盘存在滑点
